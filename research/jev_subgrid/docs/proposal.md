# Jev × 다중 교차 좌표를 이용한 3D 생성 연구 기획서

작성일: 2026-09-29 · 버전: 0.1 · 상태: 문헌 조사 및 실험 설계, 구현·실험 미수행

**가제: Learning-Free Decision-Based 3D Generation in Subgrid Edge Coordinates**

가제의 Learning-Free는 공식 Jev의 가중치를 추가 학습하지 않는 실험 설정을 뜻한다. Jev 자체가 학습 없이 만들어졌다는 뜻이 아니다. 학습한 별도 모듈을 도입한다면 제목과 기여 범위를 수정한다.

**한 문장 제안:** 기존 Subgrid Marching Tetrahedra의 모서리별 다중 교차 표현을 Jev의 순차 선택으로 생성하고, 기존 기하 복원기로 오목함·구멍·얇은 벽을 가진 3D 메쉬를 얻는다.

이번 기획의 원칙은 간단하다. 컵을 생성했다면 커피가 들어갈 공간이 있어야 한다. 속을 꽉 채운 도자기 덩어리를 놓고 “고체 라테 전용”이라고 주장하지 않는다.

## 1. 목표와 판정 범위

최종 목표는 텍스트 조건과 난수 시드만으로 새로운 형상을 생성하는 것이다. 목표 형상에는 컵, 손잡이, 속이 빈 투구, 여러 부품으로 구성된 인물 조각이 포함된다. 볼록 형상만 가능한 EGI는 본 기획에서 제외한다.

첫 결과물의 범위는 기하 메쉬다. 텍스처, PBR 재질, 리깅, 애니메이션은 후속 과제로 분리한다. 복잡한 인물은 최종 스트레스 테스트이며, 최초 성능 검증은 작고 해석 가능한 비볼록 물체에서 시작한다. 시험의 난도를 단계적으로 올리는 것이며 표현 대상을 볼록체로 제한하는 것이 아니다.

| 요구 | 본 기획의 답 | 현재 상태 |
|---|---|---|
| A는 이미 존재해야 함 | Subgrid Marching의 edge coordinates와 교차 위치 사용 | 문헌 확인 |
| 3D→A 변환이 가능해야 함 | 격자 모서리와 입력 메쉬의 교차 계산 | 저자 구현 확인 |
| A→3D 복원이 가능해야 함 | 기존 primal Subgrid 복원 경로 사용 | 문헌 확인 |
| 오목함·구멍을 배제하지 않아야 함 | 볼록성 가정 없는 표면 표현 | 표현 수준 확인, 대상별 성능 미측정 |
| AI가 같은 A를 생성한 연구가 없어야 함 | 직접 중복은 현재 검색에서 발견하지 못함 | 미확정; 계속 갱신할 조사 항목 |
| Jev가 생성에 실질적으로 관여해야 함 | 교차 패턴 및 위치를 결정 | 제안, 실험 필요 |
| 효율적이어야 함 | 선택 묶음·희소 처리·단계적 정밀화 비교 | 제안, 실험 필요 |

**아직 주장하지 않는 것:** 세계 최초 확정, 왕자급 형상 생성 성공, 모든 토폴로지의 무손실 복원, 기존 3D 모델 대비 속도 우위, Jev의 검증된 기하 추론 능력.

## 2. 기반 표현 A

고정된 공간 격자 T의 각 모서리 e에 다음을 저장한다.

`A_e = (k_e, s_e,1, ..., s_e,k_e)`

`k_e`는 음이 아닌 정수 교차 횟수다. `s_e,i`는 모서리의 시작과 끝 사이에서 정규화한 위치이며 `0 < s_e,1 < ... < s_e,k_e < 1`이다. 전체 A는 모든 모서리의 목록이다. 기하 좌표계와 격자 T도 복원에 필요하므로 파일 크기·생성 비용에서 누락하지 않는다.

이 표현과 복원은 Baktash 등의 Subgrid Marching Tetrahedra에 근거한다.[R1] 본 연구에서 새로 제안하는 것은 A 자체가 아니라, A를 Jev의 제약된 선택으로 생성하는 과정이다.

예시 모서리: `k=2, s=(0.40, 0.43)`. 가까운 두 교차를 별도로 기록하므로 얇은 벽의 양쪽 표면을 표현할 여지가 있다. 다만 이 한 모서리만으로 컵이 결정되지는 않는다. 주변 모서리와 전체 연결 구조가 함께 맞아야 한다.

복원에는 primal 경로를 먼저 사용한다. 논문에서 primal의 자기교차 방지 성질과 dual의 날카로운 특징 재현은 서로 다른 조건을 가진다. dual의 장점과 primal의 보장을 합쳐서 하나의 무조건적 보장으로 쓰지 않는다.[R1]

문헌상의 제약도 계획에 반영한다. 모서리와 만나지 않는 작은 튜브 등의 구조는 놓칠 수 있고, 입력 교차만으로 원본의 모든 기하가 유일하게 보존되지는 않는다. 닫힌 표면과 경계가 있는 표면의 보장 조건도 구분한다.[R1]

## 3. 선행연구 경계와 신규성 관리

|---|---|---|---|
| Omages [R2] | 기존 범용 모델을 3D 표현 생성에 활용 | 이미지 표현과 다중 교차 좌표의 차이 | 문제 설정의 출발점 |

2026-09-29 조사에서 논문명, edge coordinates, edge intersection counts, multi-hit와 neural/generation/diffusion 조합을 검토했다. **Subgrid의 이 표현을 직접 학습·선택해 3D를 생성하는 동일 연구는 발견하지 못했다.** 검색 부재는 연구 부재의 증명이 아니다. 현재 확인 결과의 신뢰도를 확률 수치로 꾸며 쓰지 않는다.

개발 착수 전과 투고 전에는 인용·피인용, arXiv 후속 논문, 공개 저장소 및 학위논문까지 동일성 검토를 갱신한다. 검색 결과의 단순 개수보다 아래 질문을 기록한다.

1. 생성 대상이 모서리별 가변 개수의 교차와 위치인가?
2. 그 데이터를 AI가 직접 예측하는가, 이미 생성된 SDF의 교차를 후처리로 계산하는가?
3. 동일한 Subgrid 연결·복원 구조를 쓰는가?
4. 형상 복원, 부분 완성, 무조건 생성, 텍스트 조건 생성 중 무엇을 수행했는가?

사용자의 엄격한 기준을 적용한다. 같은 A를 AI가 생성하는 직접 연구를 발견하면, Jev로 모델만 교체해도 이 후보가 독창적이라고 주장하지 않는다. 같은 A의 AI 복원·완성 연구도 중대한 충돌로 보고 사용자 기준에 따라 다시 판정한다.

한편 일반적인 “교차 데이터를 AI로 생성한다”는 주장은 X-Ray 등과 겹친다. 방어 가능한 기여는 직접 중복을 배제한 뒤에도 더 좁아야 한다. **다중 교차 표현의 제약된 생성이 품질·유효성·비용에 주는 효과**가 결과로 드러나야 한다.

## 4. 핵심 연구 질문

**Q1. 표현 적합성:** 목표 형상들의 오목함, 얇은 벽, 구멍을 제한된 데이터 예산에서 보존할 수 있는가?

**Q2. 선택 가능성:** 고정된 Jev가 텍스트 조건과 부분 A를 보고 무작위·단순 규칙보다 좋은 다음 선택을 하는가?

**Q3. 조합 가능성:** 국소 선택의 반복이 전체 구조의 일관성으로 이어지는가? 컵 손잡이가 컵 근처에 존재한다는 사실만으로 손잡이가 붙어 있다는 뜻은 아니다.

**Q4. 효율:** 모든 비용을 포함할 때 같은 품질의 일반 LLM 선택 또는 다른 생성 접근보다 유리한가?

**Q5. 실질적 기여:** 성능 향상이 Jev의 결정 때문인가, 후보 제안기나 정답 수준의 입력 요약 때문인가?

각 질문은 별도로 실패할 수 있다. Q1이 성공했다고 Q2를 증명한 것으로 취급하지 않는다. Jev가 실패해도 A의 생성 잠재력은 남을 수 있지만, 그러면 “Jev 기반 방식의 성공”이라는 결론은 내리지 않는다.

## 5. 제안 시스템

### 5.1 인코더와 데이터

메쉬를 공통 좌표계로 정규화하고 동일한 격자 규칙으로 교차 목록을 계산한다. 처음에는 균일한 정합 사면체 격자를 사용한다. 인접 셀의 정합성을 깨뜨리는 임의의 국소 격자 세분화는 첫 설계에서 사용하지 않는다.

모서리의 방향과 ID는 전역에서 고정한다. 공유 모서리의 A는 한 번만 저장한다. 방향을 뒤집을 때에는 위치 좌표의 변환과 정렬을 함께 적용한다.

교차의 중복·접선 접촉·정점 일치 등 퇴화 사례는 저자 구현의 처리 규칙을 먼저 확인한다. 임의의 허용오차를 이용해 손잡이 구멍을 제거하면서 데이터 정제라고 부르지 않는다. 변환 실패·제외 비율을 모두 기록한다.

학습 또는 예시용 데이터와 평가 데이터는 원본 물체 ID·템플릿 계열로 분리한다. 같은 컵의 크기만 바꾼 변형을 서로 다른 일반화 사례로 계산하지 않는다.

### 5.2 Jev의 상태

상태에는 사용자 조건, 현재 영역의 공간적 위치, 이미 확정된 이웃 교차 정보, 현재 형상의 관측 가능한 요약, 후보 선택의 효과를 넣는다.

기하 요약은 현재 생성 상태에서 결정적으로 계산한다. 평가 대상 정답 메쉬에서 부품 이름·교차 위치를 가져오지 않는다. 텍스트 입력만 사용하는 초기 설정에는 숨은 이미지 인코더나 별도 3D 생성기를 넣지 않는다.

세 가지 입력을 비교한다: 수치만, 수치와 이웃 구조, 수치·이웃 구조·계산 가능한 의미 요약. 인물 해부학 등 고수준 조건을 제공할 경우 사용자가 직접 준 조건과 시스템이 유추한 조건을 기록한다.

### 5.3 행동과 후보 제안

기본 행동은 교차 횟수 선택, 위치 구간 선택, 위치 정밀화, 교차 쌍 추가·삭제, 국소 수정, 정지다. 큰 변화가 필요하면 한 모서리가 아니라 작은 공유 영역의 일관된 갱신을 후보로 제안한다.

후보는 기하 규칙 또는 예시 데이터의 국소 패턴으로 구성한다. 예시에서 가져오는 것은 완성된 물체가 아니라 제한된 영역의 패턴이다. 두 방식은 별도 실험군으로 보고한다. 후보 사전의 크기·저장 비용·생성 비용도 측정한다.

정답을 후보에 포함한 실험은 선택 능력의 상한을 보는 진단 실험으로만 사용한다. 최종 생성 성능에 합산하지 않는다. 후보 안에 좋은 답이 없는 경우와 Jev가 좋은 답을 놓친 경우를 분리한다.

모든 후보의 의미를 사람이 정답에 맞춰 작성하지 않는다. 후보의 설명은 해당 교차 변화에서 계산한 효과만 포함한다. Jev의 역할이 빈 껍데기가 되지 않도록 동일 후보를 무작위·규칙·다른 모델에 그대로 제공한다.

### 5.4 선택과 샘플링

Jev의 Choice 확률을 유효 후보 위에서 재정규화해 선택한다. 결정론적 최댓값 선택과 확률 샘플링을 각각 평가한다. 이 절차는 생성 분포를 정의하지만, 반환 확률이 실제 3D 데이터 분포에 대해 보정되어 있다는 뜻은 아니다.

독립 질문 병렬화는 서로 영향을 주지 않는 결정에 우선 적용한다. 같은 상태에서 동시에 답한 인접 영역들이 자동으로 일관적일 것이라고 가정하지 않는다. 배치 크기와 충돌·수정 비용을 함께 비교한다.

Noul의 확률을 그대로 좌표나 두께로 사용하지 않는다. 위치는 명시적 구간 선택으로 얻는다. 반올림·구간 경계로 교차가 합쳐질 때 얇은 벽이 사라질 수 있으므로 위치 양자화 오차를 별도로 측정한다.

### 5.5 유효성, 복원, 되돌리기

공유 모서리의 데이터 일치, 음이 아닌 횟수, 정렬된 위치는 자료 구조 수준에서 보장한다. 닫힌 물체 실험에서는 경계 조건과 논문의 짝수합 조건 등 해당 정리의 가정을 확인한다. 이 조건이 원하는 물체의 구멍 수·연결성을 보장한다고 확대 해석하지 않는다.

선택 후 기존 primal 복원기를 적용하고 국소·전역 결함을 검사한다. 되돌리기와 재선택은 예산을 정해 수행하며 모든 비용과 실패를 포함한다. 복원기 버전, 수치 정밀도, 전처리 규칙을 고정한다.

생성 전체는 조건 → A의 선택적 구성 → 기존 복원 → 형상 평가로 구성한다. 기존 모델로 이미 완성된 3D를 만든 후 A로 바꿔놓고 본 방법의 생성 결과라고 부르지 않는다.

## 6. 실험 단계와 통과 기준

아래 수치는 문헌에서 검증된 성능이 아니라 **실험을 시작하기 전 제안하는 운영 기준**이다. 파일럿에서 평가 도구 자체의 신뢰도를 먼저 확인하고, 본 평가 전에는 기준을 고정한다.

| 단계 | 데이터·규모 제안 | 확인할 것 | 다음 단계 조건 |
|---|---|---|---|
| G0 문헌 | 직접·인접 연구 비교표 | 같은 A의 AI 생성 중복 | 직접 충돌 미발견; 미확정 항목 공개 |
| G1 왕복 | 6개 구조 계열 × 8개 형상 = 48개 | 3D→A→3D의 표현 손실 | 선정 예산에서 핵심 구조 성공률 90% 이상을 목표 |
| G2 선택 진단 | 별도 물체에서 추출한 약 240개 국소 문제 | 후보 품질과 Jev의 선택 기여 | 무작위·단순 규칙보다 반복적으로 개선 |
| G3 부분 완성 | 별도 24개 물체, 여러 누락 비율 | 주변 상태로 누락 A 복구 | 위상·거리 오차 개선, 정보 누출 없음 |
| G4 완전 생성 | 약 30개 프롬프트 × 5개 시드 | 조건만으로 새 A 생성 | 재현 가능한 의미 일치·유효성·다양성 |
| G5 복잡 형상 | 투구·다중 부품·인물 조각 | 규모 확대 시 실패 양상 | 비용과 품질 곡선 제시; 실패 포함 |

G1의 6개 계열은 컵, 고리, 얇은 쉘, 구멍 난 판, 다중 부품, 투구 유사 형상으로 구성한다. 원본의 구멍·벽 두께·연결성을 명확히 측정할 수 있는 예제를 포함한다. 실제 복잡 메쉬는 별도 평가군으로 추가한다.

G1에서는 예를 들어 8·16·32·64의 격자 해상도와 위치 정밀도를 바꾸되, 어느 설정이 충분한지는 측정으로 결정한다. 교차 횟수 상한 K를 둘 경우 잘린 교차의 비율과 사라진 구조를 반드시 보고한다. K를 작게 잡아놓고 다중 교차 표현의 장점을 증명했다고 말하지 않는다.

G2에서는 최소한 후보 내 최고 품질, Jev 선택 품질, 무작위 선택 품질을 함께 측정한다. 정답 후보가 주어지는 진단군과 실사용 후보군을 분리한다.

G3은 난점 분리를 위한 실험이다. **부분 완성 성공만으로 최종 목표 달성이라고 보고하지 않는다.** G4가 불가능하면 결과의 이름을 완성 또는 편집 연구로 바꾸고, 원래 요청한 완전 생성은 미달성으로 기록한다.

## 7. 평가 지표와 공정한 비교

| 평가 축 | 측정 | 주의점 |
|---|---|---|
| 기하 정확도 | 정규화된 양방향 표면 거리, F-score | 내부 표면도 포함 |
| 핵심 구조 | 손잡이 통로·내부 공간·부품 간 틈 보존 | 렌더 한 장으로 판단하지 않음 |
| 위상 | 연결 성분, 경계 루프, 가능한 경우 Betti 수·genus | 유효한 닫힌 표면 등 계산 가정 명시 |
| 유효성 | 자기교차, 비다양체, 퇴화 면, 복원 실패 | 후처리 전후 모두 기록 |
| 의미 일치 | 블라인드 평가, 별도 평가 모델 보조 | 생성에 쓴 Jev의 자기 채점만 사용 금지 |
| 다양성 | 시드 간 구조·형상 거리와 최근접 데이터 거리 | 왜곡과 노이즈를 다양성으로 세지 않음 |
| 비용 | 인코딩·상태 구성·후보·API·복원·수정 시간 | 실패·재시도 포함 |
| 표현 크기 | A의 실제 바이트 수, 교차 수, 부가 자료 | 압축 해제와 격자 메타데이터 포함 |

같은 A 위의 기본 비교군은 무작위 유효 선택, 계산 가능한 기하 규칙, 동일 상태·후보를 받는 일반 LLM, Jev다. 예산을 고정한 비교와 품질을 맞춘 비교를 모두 수행한다.

표현 자체의 비교에는 단일 교차로 제한한 버전, 고해상도 기존 격자 표현, 가능하면 다중 교차 A에 대한 소형 학습 모델을 포함한다. 소형 모델은 원래의 고정 Jev 설정과 학습 비용을 분리해서 보고한다.

Omages·TRELLIS 2 등과 비교할 때는 입력 조건, 출력 재질 유무, 학습 데이터·계산량, 평가 대상이 다름을 명시한다. 조건이 다른 결과를 한 순위표로 섞지 않는다. 최신 대형 모델의 시각 품질을 이길 것이라는 약속부터 하지 않는다.

## 8. 핵심 제거 실험

1. **다중 교차의 필요성:** 같은 예산에서 교차 수를 0/1로 제한한 경우와 비교한다.
2. **Jev의 기여:** 동일 후보를 무작위·규칙·일반 LLM이 선택한 경우와 비교한다.
3. **문맥의 기여:** 수치만 / 이웃 구조 / 전역 요약 추가를 비교한다.
4. **제약의 기여:** 사전 제약 / 사후 수정 / 둘 다 사용을 비교한다.
5. **선택 단위:** 개별 모서리와 작은 영역의 패턴 선택을 비교한다.
6. **정밀도의 비용:** 교차 위치 정밀화 횟수와 얇은 구조 보존의 관계를 측정한다.
7. **배치의 효과:** 병렬 질문 수 증가에 따른 시간 절감과 불일치 증가를 같이 측정한다.
8. **표현 순서 민감도:** 후보 순서·동일 의미의 라벨·좌표축 회전을 바꿔 안정성을 본다.

## 9. 주요 위험과 중단 기준

| 위험 | 조기 신호 | 대응 또는 중단 |
|---|---|---|
| 같은 A의 AI 생성 선행연구 발견 | 생성 대상과 복원 방식이 일치 | 사용자 기준상 A 후보 재선정 |
| A 자체가 목표 구조를 자주 잃음 | 원본에서 추출한 A도 손잡이·틈 소실 | 예산 범위 내 해결 안 되면 중단 |
| Jev가 공간 정보를 활용하지 못함 | 문맥을 줘도 규칙보다 지속적으로 열세 | Jev 기여 가설 기각; API 반복으로 덮지 않음 |
| 후보 제안기가 사실상 전부 생성 | Jev와 무작위 결과 차이가 거의 없음 | 기여 재정의 또는 중단 |
| 국소 선택이 전역 구조로 이어지지 않음 | 부분 완성만 되고 처음부터는 붕괴 | 완전 생성 미달성으로 기록 |
| 비용 폭증 | 후보·수정·호출이 예산을 초과 | 묶음 선택 검증 후에도 실패하면 효율 주장 철회 |
| 템플릿 암기 | 새 구조·부품 조합에서 급락 | 데이터 분할 강화, 일반화 범위 축소 |
| 복원 보장 오용 | dual 또는 열린 경계에서 결함 발생 | 보장 조건 분리, 실패율 공개 |

중단은 실패를 숨기는 절차가 아니라 연구비와 시간을 아끼는 절차다. 왕자 한 명 뽑는 데 왕국의 연간 예산이 들어가면 “효율적인 3D 생성”은 제목에서 내려와야 한다.

## 10. 일정·자원·산출물

일정은 개발자 1명 기준의 초기 추정이며, 접근 권한·API 지연·기하 디버깅에 따라 달라진다. 현재 구현 시작 승인을 요청하는 일정표가 아니라 후속 실행을 위한 계획이다.

| 기간 | 작업 | 검토 가능한 산출물 |
|---|---|---|
| 1주차 | 문헌 경계 확정, 저자 구현 검토, G1 | 비교표, 왕복 오류 지도, 실패 목록 |
| 2주차 | 상태·후보 설계, G2 | Jev 선택 기여와 후보 상한 보고 |
| 3주차 | 제약·복원·부분 완성, G3 | 누락률별 정확도·위상·비용 곡선 |
| 4주차 | 완전 생성 G4, 중간 중단 판정 | 새 프롬프트·시드별 결과와 실패 |
| 5~6주차 | 복잡 형상 G5, 제거 실험, 논문 초안 | 재현 가능한 실험 보고서 |

필수 자원은 기하 처리 환경, 적법하게 사용할 수 있는 메쉬, 공식 Jev API 접근, 비교 모델 접근이다. GPU 필요량은 비교 모델 및 평가 방식에 따라 정한다. 실험 전 처리량을 측정하지 않고 GPU 수·총 비용을 확정하지 않는다.

비용 모델은 다음처럼 기록한다.

`총비용 = 데이터 변환 + 상태/후보 생성 + 모든 모델 호출 + 복원 + 검증/수정 + 평가`

API 가격은 실행일의 공식 가격으로 재확인한다. 파일럿에서 물체당 토큰·요청 수와 성공률을 측정한 후 예산 상한을 정한다. 고객별 미세조정이 제공되지 않는 현재 공식 Jev 설정을 전제로 하며, 다른 결정 모델을 학습하면 별도 실험으로 표기한다.[R7–R9]

## 11. 논문으로 주장할 수 있는 결과

최선의 결과는 다음 세 기여다.

1. 기존 다중 교차 좌표에 대한 명시적 조건부 생성 절차와 제약 처리.
2. 같은 자원 예산에서 얇은 구조·구멍을 보존하는 효과에 대한 실증.
3. Jev의 구조화된 선택이 유효성·비용·품질 중 어떤 항목을 개선하는지에 대한 통제 실험.

효과가 확인되지 않으면 가제의 효율성·범용성 표현을 사용하지 않는다. 표현의 신규성, 모델의 신규성, 결합 방법의 신규성, 실험상의 신규성을 구분한다. “최신 API를 붙였다”만 남으면 연구 기여가 부족하다.

**현재 착수 판단:** G0–G2를 먼저 수행할 가치가 있는 후보. 완전 생성 및 효율 우위는 미검증. 코드 작성은 본 기획서에 포함하지 않았다.
