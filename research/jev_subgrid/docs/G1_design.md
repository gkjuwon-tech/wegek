# G1 설계·구현 노트 — 3D → A → 3D 왕복

기획서(`docs/proposal.md`) 6장의 G1 단계를 구현하면서 내린 결정과 그 근거를 기록합니다.
숫자 결과는 자동 생성되는 `results/g1/report.md`에 있고, 이 문서는 "왜 이렇게 만들었는가"를 다룹니다.

## 1. 저자 구현 검토 (1주차 작업: "저자 구현 검토")

검토 대상: `subgrid-marching` **1.0.0** (PyPI 휠, MIT, Baktash·Gillespie·Crane) 및 저장소
`hbaktash/subgrid-marching`의 소스·문서. 확인한 사실만 적습니다.

| 항목 | 확인 내용 | 우리 구현에서의 처리 |
|---|---|---|
| 격자 | `n³` 정육면체 × 5 사면체, 정육면체 짝/홀(`ix+iy+iz`)에 따라 분할이 번갈아 바뀌는 정합 격자. 노드 id `z(n+1)²+y(n+1)+x`, 좌표 `(i·dx−0.5)·2`, `dx=1/(n−1)` → 노드 `0..n−1`이 `[−1,1]`, 마지막 노드층은 `+1` 바깥 | `jevsg.grid.TetGrid`가 **비트 단위로 동일하게** 재현 (사면체 순서·정점 순서 포함) |
| 입력 A의 형식 | 명시적 `.npz`: `vertices, tets, edges(i<j), isect_offsets, isect_ts`(모서리 안에서 오름차순) | `jevsg.decode.explicit_input_arrays` |
| 역방향 모서리 | `(j,i)`로 조회하면 `t → 1−t`로 뒤집고 역순 정렬 | A는 항상 정규 방향 `(i<j)`으로만 저장 |
| 복원 | primal은 법선을 쓰지 않음. 기본은 조합적(combinatorial) 병합 → 모든 사면체가 even-sum이면 물샐틈없고 방향성 있는 출력 | 이 기본값 그대로 사용 (`scoop_bulge=1e-3`) |
| `non_even_tets` | 어떤 사면체 면의 교차 합이 홀수인 사면체 수. 닫힌 입력이면 0이어야 함 | 매 실행 기록. A 자체의 홀수 면 수(`odd_faces`)도 독립적으로 계산 |
| 저자 교차 질의 | FCPW BVH 광선 질의, BVH 좌표가 **float32**, 입력에 시드 고정 평행이동(크기 0.01)으로 퇴화 회피, 비강건 모드에서 광선을 `1e-6` 연장 | 우리는 정확 술어 + 기호적 섭동(아래 2장)으로 대체. 교차 검증에만 저자 파이프라인 사용 |
| 발견한 동작 | 출력 면이 하나도 없을 때(예: 거친 격자가 얇은 고리를 완전히 놓침) `primal_from_mesh`가 geometry-central 단언(`unreferenced vertex 0`)으로 **예외 발생** | 교차 검증에서 예외를 기록하고, 우리 출력도 비어 있으면 "일치"로 판정 |
| 보장의 조건 | 자기교차 없음은 primal 구성의 성질(부록 D). dual의 날카로운 특징 재현과 primal의 보장은 별개 | G1은 primal만 사용. 자기교차는 가정하지 않고 매번 정확 술어로 **검사** |

## 2. 인코더: 메쉬 → A

### 2.1 무엇을 계산하는가

격자 모서리 `e=(i,j)`, `i<j`마다 입력 삼각형 메쉬와의 교차 위치 `s∈(0,1)` 목록(오름차순). 교차는
"모서리가 삼각형 내부를 가로지른다"로 정의하고 다섯 개의 부호 판정으로 결정합니다.

1. 노드 `i`, `j`가 삼각형 평면의 서로 반대편인가 (`plane_side` 두 번)
2. 모서리 직선이 삼각형의 세 변에 대해 같은 쪽으로 지나가는가 (`line_side` 세 번)

### 2.2 정확성 보장 (왜 "대부분 맞음"이 아니라 "항상 맞음"인가)

* 모든 판정은 float64 입력값에 대한 **정확한 부호**입니다. 먼저 Shewchuk의 오차 한계로 float 계산을
  걸러내고, 믿을 수 없는 경우에만 정수 스케일링 정확 산술로 다시 계산합니다 (NumPy object 배열로 벡터화).
* 행렬식이 정확히 0인 퇴화(격자 노드가 표면 위, 모서리가 메쉬 변·정점을 정확히 통과 등)는
  **격자 전체를 무한소 벡터 `δ=(ε, ε², ε³)`만큼 평행이동**한 것으로 간주해 해소합니다. 모든 판정이
  하나의 실제 기하적 섭동으로 설명되므로 판정들끼리 서로 모순될 수 없습니다.
  * 평면 판정의 1차 항: `n·δ` (`n = (b−a)×(c−a)`) → `n`의 첫 비영 성분의 부호
  * 직선 판정의 1차 항: `δ·((x−y)×(q−p))` → 해당 외적의 첫 비영 성분의 부호
  * 평행이동에 대해 두 판정 모두 정확히 1차(2차 항 `δ×δ=0`)라서 이 규칙이 완전합니다.
    직선 판정의 1차 항이 사라지는 경우(메쉬 변이 모서리와 평행)는 평면 판정에서 먼저 걸러집니다.
* 결과: **닫힌 입력(mod 2 의미; 자기교차 허용)이면 모든 사면체 면의 교차 합이 짝수**입니다. 사면체 면의
  경계는 닫힌 곡선이고, 일반 위치의 닫힌 곡면과 닫힌 곡선의 교차 수는 짝수이기 때문입니다.
  테스트(`tests/test_encode.py`)는 면이 격자 평면 위에 정확히 놓이고 꼭짓점이 격자 노드인 상자까지
  포함해 이를 확인합니다. 또한 모든 모서리에서 `k mod 2 = inside(i) xor inside(j)`를 확인합니다.
* 저자 파이프라인과 비교: 같은 격자·같은 메쉬에서 출력 연결구조가 **면 단위로 동일**하고, 정점 좌표 차이는
  저자 BVH의 float32 정밀도(~1e-6) 수준입니다 (`tests/test_decode.py`, G1 보고서 2장).

### 2.3 위치 `s` 와 퇴화 기록

`s = v_i / (v_i − v_j)` (`v`는 평면까지의 부호 있는 값). 섭동으로만 결정된 교차는 `s`가 정확히 0 또는 1이
될 수 있으므로 `[2⁻⁴⁰, 1−2⁻⁴⁰]`로 클램프하고 **횟수를 기록**합니다. 한 모서리 안에서 float `s`가 같아지는
드문 경우는 `nextafter`로 분리하고 역시 기록합니다. 어떤 교차도 삭제하거나 "정제"하지 않습니다
(기획서 5.1).

### 2.4 비용

삼각형마다 격자 좌표 경계상자 안의 노드에서 평면 판정을 한 번씩 하고(노드 공유), 부호가 바뀐 모서리만
직선 판정을 합니다. 모양이 같은 경계상자끼리 묶어 밀집 배열로 벡터화합니다.

## 3. A의 표현과 크기

* 메모리: 희소 CSR — 교차가 있는 모서리 id(오름차순), 오프셋, 위치 (`jevsg.representation.EdgeCoordinates`).
* 불변식(자료구조 수준 보장, 기획서 5.5): id 오름차순·범위 안, `k>0`만 저장, `0<s<1`, 모서리 안 엄격 증가.
* 직렬화(`SGEA` v1, 리틀엔디언): 17바이트 헤더(`magic, version, 격자 scheme id, n, bits, M, N`) +
  모서리 id 간격 LEB128 + `k−1` LEB128 + 위치(float64 또는 `b`비트 구간 번호를 비트 패킹).
  격자는 (scheme, n)으로 완전히 정해지므로 추가 바이트가 없습니다. **보고하는 "A 크기"는 이 바이트 수 전체**이고,
  zlib 압축 크기를 함께 적습니다. 정규화 변환(스케일·평행이동)은 격자 좌표계에서 비교하므로 포함하지 않았습니다
  (필요하면 +32바이트).

### 3.1 위치 정밀도 (`q{b}`)

위치는 `2^b`개 구간 중 하나를 고르는 것으로 저장하고, 복원 시 구간 중앙값을 씁니다(기획서 5.4의
"명시적 구간 선택"). 한 모서리의 교차 여러 개가 같은 구간에 떨어지면 **k를 바꾸지 않고** 인접 구간으로
밀어냅니다(앞으로 밀기 → 끝을 넘으면 뒤로 당기기). 밀려난 횟수는 보고합니다. 구간 수보다 교차가 많으면
조용히 합치지 않고 오류로 실패합니다.

### 3.2 교차 수 상한 (`K{c}`)

모서리당 최대 `c`개. 초과분은 **가장 가까운 인접 쌍부터 둘씩** 제거합니다. 짝 단위 제거는 모든 모서리의
홀짝을, 따라서 모든 면의 홀짝을 보존하므로 닫힌 곡면의 even-sum 조건이 유지됩니다. 가장 가까운 쌍은
곧 가장 얇은 벽·틈이므로, 상한이 무엇을 잃게 하는지가 그대로 드러납니다. `K1`은 모서리당 0/1 교차인
단일 교차 표현으로, 제거 실험 8.1의 비교군입니다.

## 4. 시험 형상과 기준 메쉬

* 6개 계열 × 8개 = 48개 (`jevsg.shapes.library`): 컵(손잡이 유무), 고리(단일·사슬), 얇은 쉘(닫힌 속빈 공,
  그릇, 구멍 1·2개 공), 구멍 난 판(구멍 1/2/4/6), 다중 부품(2~5개, 틈 조절), 투구(눈 구멍 1~3, 볏 유무).
* 각 계열의 변형 0–3은 기본 자세, 4–7은 무작위 회전(격자 정렬 벽과 비스듬한 벽 모두 포함).
* 벽 두께·틈·관 지름을 로그 스케일 사다리(대략 0.03–0.16)로 배치해, 모든 시험 해상도에서 격자 간격보다
  얇은 구조와 두꺼운 구조가 함께 들어가도록 했습니다.
* 설계된 정답: 표면 성분 수, 성분별 genus, 그리고 **프로브** — 반드시 공기여야 하는 점(컵의 커피 공간,
  손잡이 통로, 부품 사이 틈, 속빈 공의 내부, 눈 구멍)과 반드시 재료여야 하는 점(얇은 벽의 한가운데 등).
  "컵에 커피 공간이 있는가"를 렌더 한 장이 아니라 일반화 감김수(winding number) 판정으로 확인합니다.
* 기준 메쉬 = SDF의 marching cubes(가장 얇은 설계 특징에 복셀 3개 이상). 사용 전 검증: 닫힌 방향성
  2-다양체, 정확 자기교차 0, 설계 성분 수·genus 일치, 모든 프로브가 설계한 쪽에 최소 특징의 25% 이상
  여유거리를 두고 위치. 실패하면 **수리하지 않고 제외·보고**합니다.

### 4.1 기준 메쉬 생성 중 발견·수정한 문제 (평가 실행 전)

투명성을 위해 기록합니다. 두 문제 모두 **어떤 복원 결과도 보기 전에** 기준 메쉬 검증 단계에서 발견했습니다.

1. **marching cubes 정점 겹침.** SDF 표본이 0에 매우 가까우면 보간 정점이 격자 모서리 끝점에 정확히 놓여
   여러 정점이 같은 위치가 되고, 면적 0 삼각형과 접촉(정확 검사기에서 자기교차로 판정)이 생겼습니다
   (48개 중 9개). 표본을 float64로 계산하고 `|f| < 1e-4·복셀`인 값을 0에서 밀어내어 해결했습니다(표면 이동
   ≤ 1e-4 복셀).
2. **투구 테두리의 예각 쐐기.** 적도 아래를 평면으로 자르면 안쪽 테두리에 예각(~52°) 쐐기가 생기고, 그 안에서
   marching cubes가 8개 면짜리 고립 조각을 만들었습니다(`helmet_7`). 테두리를 중심을 지나는 원뿔로 자르도록
   바꿔 테두리 면이 껍질과 직각이 되게 했습니다. 투구 8개 모두의 기준 메쉬가 이 규칙으로 다시 생성됐습니다.

## 5. 평가 (기획서 7장 대응)

| 기획서 평가 축 | G1 구현 |
|---|---|
| 기하 정확도 | 양방향 **점-삼각형 정확 거리**(샘플↔표면), Chamfer-L1/L2, Hausdorff, 95% 분위, F-score@0.5%·1% (모두 기준 메쉬 대각선 비). 내부 표면 포함 |
| 핵심 구조 | 프로브(공기/재료) 판정, 구조 종류별(`cavity`, `handle_hole`, `hole`, `gap`, `void`, `thin_wall` …) 집계 |
| 위상 | 연결 성분 수, 성분별 genus(오일러 특성), 경계 루프 수, 방향 가능성 |
| 유효성 | 경계·비다양체 모서리, 비다양체 정점, 퇴화·중복 면, **정확 술어 자기교차 검사** |
| 표현 크기 | SGEA 바이트(헤더·격자 식별 포함) + zlib, 교차 수, 활성 모서리 수, k≥2 모서리 비율 |
| 비용 | 인코딩·복원·평가 시간 |

**G1 통과 판정(핵심 구조 성공)** = 닫힌 방향성 2-다양체 ∧ 성분 수 일치 ∧ 성분별 genus 일치 ∧ 모든 프로브
통과. 목표(기획서 6장, 실행 전 고정): 선정 예산에서 성공률 ≥ 90%. 예산은 측정 후 "목표를 만족하는
설정 중 A 크기 중앙값이 가장 작은 것"으로 선정합니다.

## 7. G1이 말해주지 않는 것 (기획서 1장 "아직 주장하지 않는 것" 유지)

* G1은 **표현의 손실**만 잽니다. Jev는 아직 관여하지 않았고, 생성 능력(Q2–Q5)에 대해 아무것도 증명하지 않습니다.
* 기준 형상은 절차적으로 만든 비교적 단순한 물체입니다. 실제 스캔·아티스트 메쉬는 별도 평가군이 필요합니다.
* 닫힌 표면만 다룹니다. 경계가 있는 표면은 even-sum 조건이 성립하지 않으며(테스트로 확인), 보장 조건이 다릅니다.
